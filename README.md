# DeepSeek 高峰低峰自动切换 (astrbot_plugin_deepseek_peak_switch)

![DeepSeek 高峰低峰自动切换](logo.png)

按 DeepSeek 官方高峰/低峰时段，为不同 bot 自动切换使用不同的模型提供商。

- 高峰时段自动使用「高峰模型」，低峰时段自动使用「低峰模型」；
- 时段可定时从 DeepSeek 官方文档自动更新（官方调整后无需改动插件）；
- 支持多 bot 独立配置、支持强制切换与状态查询。

## 高峰/低峰时段说明

| 时段 | 时间（北京时间） |
| --- | --- |
| 高峰 | 周一至周五 09:00-12:00、14:00-18:00 |
| 低峰 | 其余所有时间（含周末全天与工作日其余时间） |

> 上表为插件内置默认值；开启「定时拉取官方文档」后，插件会自动解析官方最新时段并覆盖默认值。拉取失败时自动回退：上次成功结果 → 内置默认。

## 工作原理

插件在每条消息进入 LLM 之前判断：该消息来自哪个 bot、当前处于高峰还是低峰、对应应该使用哪个模型提供商，然后让这条消息的 LLM 请求使用该提供商。

- 不修改全局默认模型；
- 不写会话偏好；
- 未配置规则的 bot 完全不受影响；
- 配置中的提供商不存在时自动跳过并记录日志（不会让机器人报错）。

## 安装

1. 将本插件文件夹放入 `AstrBot/data/plugins/` 目录（或下载 Release 的 zip 解压放入）；
2. 在 AstrBot WebUI 的插件管理页启用/重载插件；
3. 打开插件配置页，添加切换规则。

## 配置

| 配置项 | 说明 |
| --- | --- |
| 启用自动切换 | 总开关（默认开） |
| 多 bot 切换规则 | 每个规则包含：备注名、bot 列表、低峰模型、高峰模型 |
| 默认高峰/低峰模型（可选） | 未匹配任何规则的 bot 使用；留空则不处理 |
| 定时拉取官方文档 | 是否自动更新时段（默认开） |
| 拉取间隔（小时） | 默认 24 |
| 官方文档地址 | 默认官方中文定价页，一般无需修改 |

### 规则怎么填

- **bot**：填「平台实例 ID」或「QQ号」，可填多个；
- 不知道填什么？对 bot 发送 `/ds_switch_status`，输出里的 `platform_id` 和 `self_id` 直接复制填入即可；
- **低峰模型 / 高峰模型**：下拉选择（列出你在 AstrBot 中已配置的模型提供商）；某一档留空，则该时段不做切换。

### 准备模型提供商

AstrBot 中每个「模型提供商」条目对应一档模型配置。若想让高低峰使用不同模型，请为两档各建一个提供商（相同 API Key、不同模型名），例如：

| 用途 | 模型名示例 |
| --- | --- |
| 低峰（折扣时段） | `deepseek-v4-pro` |
| 高峰（高价时段，选更省成本的） | `deepseek-flash` |

然后在插件里把两档分别选上即可。

## 指令

| 指令 | 权限 | 说明 |
| --- | --- | --- |
| `/ds_switch_status` | 所有人 | 查看当前时段、命中规则、当前将使用的模型、时段来源等 |
| `/ds_switch_refresh` | 管理员 | 立即拉取官方文档并更新时段 |
| `/ds_switch_force peak/offpeak/auto` | 管理员 | 强制高峰/低峰/恢复自动（仅对当前 bot 生效，重载插件后恢复自动） |

## 常见问题

- **没有配置规则会怎样？** 不做任何切换，插件零干预。
- **强制模式会一直生效吗？** 仅保存在内存中，插件重载/重启后自动恢复「按时间切换」。
- **官方文档拉取失败会怎样？** 自动回退：上次成功结果 → 内置默认，并在状态指令中显示失败原因。
- **想让某个 bot 不参与切换？** 不给它配置规则即可（也不要用默认规则字段）。
- **切换是否影响语音、图片等其他功能？** 不影响，只改变该 bot 对话使用的主模型提供商。
