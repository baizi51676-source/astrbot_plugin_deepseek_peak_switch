# DeepSeek 高峰低峰自动切换 (astrbot_plugin_deepseek_peak_switch)

![DeepSeek 高峰低峰自动切换](logo.png)

按 DeepSeek 官方高峰/低峰时段，为不同 bot 自动切换使用不同的模型提供商。

- 高峰时段自动使用「高峰模型」，低峰时段自动使用「低峰模型」；
- 时段自动获取（拉取官方文档，含**法定节假日识别**），也支持**手动自由配置**；
- 支持多 bot 独立配置、强制切换与状态查询。

## 高峰/低峰时段说明

| 时段 | 时间（北京时间） |
| --- | --- |
| 高峰 | 周一至周五 09:00-12:00、14:00-18:00（不含中国法定节假日） |
| 低峰 | 其余所有时间（含周末全天、法定节假日全天） |

> 上表为内置默认值；自动模式下插件会定时解析官方最新时段，官方调整后无需更新插件。数据来源与回退顺序：官方文档（主地址 → 备用地址）→ 上次成功缓存 → 内置默认。

## 两种时段模式

### 1）自动模式（默认）

插件定时拉取 DeepSeek 官方定价文档解析时段，自动兼容官方**新旧措辞与中英文页面**；**法定节假日全天按低峰处理**（节假日数据在线获取并缓存，也可在配置里手动补充日期）。

### 2）手动模式

想自己定义时段时，把「时段模式」设为**手动**，然后配置：

| 配置项 | 说明 | 示例 |
| --- | --- | --- |
| 自定义时段含义 | 所填时段代表高峰还是低峰 | 所填为高峰时段（其余为低峰） |
| 自定义星期 | 1-7（1=周一）或中文，支持区间 | `["1-5"]`、`["1,3,5"]`、`["一-五"]` |
| 自定义时段 | HH:MM-HH:MM，可多个、支持跨天 | `["09:00-12:00","14:00-18:00"]` |

例如："只把工作日晚间 20:00-23:00 当高峰" → 含义选「所填为高峰时段」，星期填 `["1-5"]`，时段填 `["20:00-23:00"]`。

## 工作原理

插件在每条消息进入 LLM 之前判断：该消息来自哪个 bot、当前处于高峰还是低峰、对应应该使用哪个模型提供商，然后让这条消息的 LLM 请求使用该提供商。

- 不修改全局默认模型；不写会话偏好；
- 未配置规则的 bot 完全不受影响；
- 配置中的提供商不存在时自动跳过并记录日志（不会让机器人报错）。

## 安装

1. 将本插件文件夹放入 `AstrBot/data/plugins/` 目录（或下载 Release 的 zip 解压放入）；
2. 在 AstrBot WebUI 的插件管理页启用/重载插件；
3. 打开插件配置页，添加切换规则。

## 配置

| 配置项 | 说明 |
| --- | --- |
| 启用自动切换 | 总开关（默认开） |
| 时段模式 | 自动（拉取官方文档）/ 手动（自定义时段） |
| 自定义时段含义 / 星期 / 时段 | 手动模式使用（见上文示例） |
| 定时拉取官方文档 | 自动模式下是否自动更新时段（默认开） |
| 拉取间隔（小时） | 默认 24 |
| 官方文档地址 / 备用地址 | 默认官方中文页 / 英文页 |
| 识别中国法定节假日 | 节假日全天按低峰（默认开） |
| 节假日数据地址 | 支持 `{year}` 占位符，默认公开数据源 |
| 手动节假日日期 | 补充日期，如 `["2026-10-01"]` |
| 多 bot 切换规则 | 每个规则：备注名 + bot 列表 + 低峰模型 + 高峰模型 |
| 默认高峰/低峰模型（可选） | 未匹配规则时的兜底；留空则不处理 |

### 规则怎么填

- **bot**：填「平台实例 ID」或「QQ号」，可填多个；对 bot 发送 `/ds_switch_status` 可查看并复制；
- **低峰模型 / 高峰模型**：下拉选择已配置的「模型提供商」；某一档留空则该时段不做切换。

### 准备模型提供商

AstrBot 中每个「模型提供商」条目对应一档模型配置。想让高低峰使用不同模型，请为两档各建一个提供商（相同 API Key、不同模型名），例如：

| 用途 | 模型名示例 |
| --- | --- |
| 低峰（折扣时段） | `deepseek-v4-pro` |
| 高峰（高价时段，选更省成本的） | `deepseek-flash` |

## 指令

| 指令 | 权限 | 说明 |
| --- | --- | --- |
| `/ds_switch_status` | 所有人 | 查看时段模式、当前时段、节假日数据、命中规则与当前将使用的模型 |
| `/ds_switch_refresh` | 管理员 | 立即刷新时段（手动模式下仅刷新节假日数据） |
| `/ds_switch_force peak/offpeak/auto` | 管理员 | 强制高峰/低峰/恢复自动（仅当前 bot，重载后恢复） |

## 常见问题

- **没有配置规则会怎样？** 不做任何切换，插件零干预。
- **法定节假日怎么算？** 节假日数据自动获取（也可手动补充），节假日全天按低峰处理；可在配置中关闭。
- **官方改文案会导致失效吗？** 解析器兼容新旧措辞与中英文，并会自动尝试备用页面；全部失败时回退到上次成功/内置默认，状态指令里可见原因。
- **强制模式会一直生效吗？** 仅内存保存，插件重载/重启后恢复自动。
- **手动模式还会联网吗？** 不会再拉取文档时段；若开启节假日识别，仅拉取节假日数据。
